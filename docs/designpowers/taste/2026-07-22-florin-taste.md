# Taste Profile: token-tracker / Florin

**Date:** 2026-07-22  
**Quality level:** Flagship (GitHub README hero — every pixel intentional)

## Existing Design System
Project-local Florin kit (`docs/concepts/kit/FLORIN.md`, hotlane sheet, brandkit board). No separate Figma DS.

### Taste Signals from the System
- Colour: restrained — `#0B0B0B` / `#EDEAE2` / one accent `#2B6CFF`
- Density: generous dark void; engraving does the work
- Personality: mint-honest, epic, peaceful — not SaaS chrome
- Typography: Fraunces (florin) · Cinzel family (count line) · mono for `flr`

### Where the User Wants to Evolve
- Flat bright “florin” sticker feels basic vs the mural
- Corner F + palm F feels duplicitous
- Count line craft is good — type treatments should *pair* with it
- Palm coin should carry logo authority; golden-spiral composition
- Higher concept: Renaissance epic + craft + peacefulness; anti badge/chart flare

## Emotional Target
Quiet awe. Settlement myth, not marketing. A mint and a toll — counted, believed, local.

## Aesthetic Principles

1. **One world, many marks** — Campaign drops (ASCII, Charon, Pacioli) share a mint; they don’t stack as competing logos in one skim.  
   _Test: At 900px, can you name the single emotional focal in under a second?_

2. **Palm before chrome** — The minted florin in the hand is the lettermark *in situ*. Overlay lockups must earn their place or leave.  
   _Test: Remove the corner — does the brand still feel named by the coin + quiet type?_

3. **Type that belongs to the etch** — Wordmarks share opacity, texture, and family with “Count every token.” No flat white stickers.  
   _Test: Do florin + count line feel like siblings?_

4. **Spiral, not stack** — Composition follows a golden spiral from the coin/hand; void breathes.  
   _Test: Is there a hard top band or poster sandwich?_

5. **Blue is rare** — `#2B6CFF` only on assay/glow. Restraint makes the coin holy.  
   _Test: Is there a second accent?_

## Quality Level
**Flagship** for the README mural. Compress for GitHub weight without killing stipple.

## Craft Standards
- Shadows: engraving density, not drop-shadow UI
- Borders: none on mural lockups; no card chrome
- Colour: 90%+ void/bone; blue ≤5% of frame
- Type: florin quieter + higher craft; count line ~0.35–0.45× and blended
- Whitespace: generous dark — peacefulness
- Animation: none for PNG; static breath only if ever motion

## Personality
A Florentine clerk who also ferries the night river — precise, grave, kind. Speaks softly. Dresses in bone ink and one blue seal.

## Decision (2026-07-22)
**Direction A — Palm is the mark.** Corner lockup killed. Palm coin owns identity. Quiet florin + count line as etch siblings.
