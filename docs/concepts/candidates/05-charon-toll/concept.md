# 05 — Charon-Toll

## Thesis
Each session costs a **crossing fare** — one coin in a giant palm.

## Craft note
Charon’s obol / Doré scale — toll metaphor, not underworld costume as the mark.

## Ground / accent
Cream + cyanotype blue · **one** warm coin accent (gold) *or* blue toll on dark alt — never both gold and blue.

## Assets
- Primary: `hero.png` (toll crop)
- Alt: `alt-dark.png` (blue toll on black)
- Alt: `alt-wide.png` (full scene v2)

## Strengths
- Strongest myth/atmosphere craft
- Coin action is literal (handing the token)
- Distinct from every CLI heat-map logo

## Kill risks
