## Rules

- Wordmark text stays out of the hero PNG tagline slot — name only.
- Accent is **only** `#2B6CFF` (EPROM window). Do not add a second accent.
- Clear space ≈ height of the coin disc.
- Minimum digital width: icon 24px · horizontal lockup 160px.

## PNG export (optional)

# if inkscape available
inkscape docs/concepts/svg/florin/token-tracker-florin-icon.svg --export-type=png --export-width=256
