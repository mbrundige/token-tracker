## Inspiration board — Arcade × Terminal × Token (ACTIVE)

**Thesis:** AI tokens are the coins. Spend shows up like a high score. Glass is CRT/phosphor, not neon sunset. Fun = wink + craft, not purple vaporwave.

**Hard kill:** heat-grid · purple overload · cute robot (unless sharp/funny) · contribution graphs · baked taglines.

**Hard rules:** wordmark `token-tracker` only in hero PNG · dark ground · one accent · icon ≤32px · ASCII craft visible in the mark · modern elegance (arcade DNA as structure, not sticker pack).

### 1. Insert Token ★ LEAD

```
  ┌──────────────────────────────┐
  │  ░░░░░ INSERT TOKEN ░░░░░    │
  │         ┌───┐                │
  │         │ ● │  ← coin chute  │
  │         └─┬─┘                │
  │    █ token-tracker           │
  │    ▔▔ (block cursor blink)   │
  └──────────────────────────────┘
  Icon: chute mouth + one coin disc
```

- **DNA:** Arcade “INSERT COIN” + VT100 prompt + tokens-as-currency joke.
- **Accent:** Phosphor green `#33FF66` on `#0A0C0A` (or bone type + green chute rim — one lit family).
- **Take:** The product joke in one glance. Coin chute = unique silhouette vs every CLI logo.
- **Leave:** Flashing “PRESS START” spam; chrome bezel jewelry; second accent.
- **Risk:** Reads as a game, not a spend tool, if the chute outweighs the wordmark.

### 2. Hi-Score

```
  ╔════════════════════════════╗
  ║  HI-SCORE                  ║
  ║  1  token-tracker  999999  ║
  ║  2  .............. ......  ║
  ║  3  .............. ......  ║
  ║         █                  ║
  ╚════════════════════════════╝
  Icon: "1UP" block or "#1" cell
```

- **DNA:** Marquee HISCORE table + mono ledger energy (CLI report kinship).
- **Accent:** Amber `#FFB000` on `#0D0B08` (cabinet marquee warmth, not gold heat tiles).
- **Take:** Spend-as-flex. Table rhythm maps to usage reports without a chart.
- **Leave:** Fake rival initials (AAA/BOB); rainbow rank colors; “GAME OVER” drama.
- **Risk:** Looks like a retro-game README theme pack if the table is too busy at hero width.

### 3. Cabinet

```
       ___________
      /  ▓▓▓▓▓▓▓  \     ← CRT glass, scanlines
     |  token-     |
     |  tracker █  |
     |_____________|
        |  ○  |         ← 1-button / stick stub
       /|_____|\
      /__COIN___\       ← slot lip
  Icon: cab silhouette, screen = `tt`
```

- **DNA:** Side/front cab + phosphor screen wordmark + coin lip.
- **Accent:** Green glass on matte cab black; bone stick/button optional but mute.
- **Take:** Hardware object = brand. Screen carries terminal DNA; lip carries arcade.
- **Leave:** Full 3D render porn; side-art dragons; purple attract-mode glow.
- **Risk:** Busy at 32px — cab silhouette must simplify hard or icon fails.

### 4. Ticket

```
  .-------------------------------.
  | TOKEN-TRACKER    **** 0142    |
  | ∷∷∷∷∷∷∷∷∷∷∷∷  tear →          |
  | █ CREDITS: ▓▓▓▓▓░░░░  tok     |
  '-------------------------------'
  Icon: stub end with star punch ★
```

- **DNA:** Arcade redemption ticket + receipt/ledger (CLI accounting wink).
- **Accent:** Bone `#E8E0D5` on near-black; single red-orange star punch `#FF4D2E` only if needed — prefer bone-only for one-accent purity.
- **Take:** Tokens → tickets → proof of play. Tear edge = craft texture without scanline cliché.
- **Leave:** Carnival fonts; barcode as decoration; pastel stub paper.
- **Risk:** Reads “event merch” not “dev tool” if the stub is too paper-real.

### 5. Stick

```
        ┌──┐
        │▓▓│  ← stick top (block pixel)
        └┬─┘
      ═══╪═══ base
         │
   █ token-tracker
  Icon: stick + base only (no wordmark)
```

- **DNA:** Joystick as block-cursor cousin — same square language as VT100 `█`.
- **Accent:** Phosphor green stick head; bone wordmark OR all-green lockup.
- **Take:** Minimal, sharp, funny without a mascot. Pairs clean with CLI screenshots.
- **Leave:** Soft 3D ball-top; anime stickers; dual-stick fighter chrome.
- **Risk:** Too abstract — “random game icon,” not token-tracker, unless chute/credit cue appears somewhere in the set.

### 6. Continue? ★ wild card

```
  ┌─────────────────────┐
  │  CONTINUE?          │
  │                     │
  │      9 . . .        │  ← countdown digits, bitmap
  │                     │
  │  CREDIT  0   ←──┐   │
  │  token-tracker █┘   │
  └─────────────────────┘
  Icon: single digit `9` with scanline
```

- **DNA:** Continue screen anxiety + credit=0 joke (= out of tokens / budget).
- **Accent:** Amber digits + bone wordmark on black (one warm system).
- **Take:** Emotional hit — budget tension is the product. Sharp funny, no robot.
- **Leave:** Skull/game-over art; timer animation in static PNG; panic red everywhere.
- **Risk:** Dark/anxious tone may undercut “FUN” if countdown dominates the wordmark.

**Taste filter:** User likes medieval Florence, Medici, banking dynasties, art patronage. Prefer solemn/sharp over costume Renaissance Faire. Avoid Rothschilds (politics), over-cute Midas, crypto-gold kitsch.
